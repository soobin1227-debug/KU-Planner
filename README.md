# 📚 KU Planner (고려대학교 학업 일정 매니저)

과제, 시험, 발표 일정이 늘어나면서 대학생들은 여러 플랫폼에 흩어진 학업 일정을 관리하는 데 어려움을 겪습니다.

KU Planner는 고려대학교 학생들을 위한 학업 일정 관리 웹 애플리케이션으로, 과제와 시험 일정을 한 곳에서 체계적으로 관리하고 D-Day를 자동 계산하여 중요한 일정을 놓치지 않도록 돕습니다.

GitHub Pages를 통해 배포되었으며 별도의 회원가입 없이 브라우저에서 바로 사용할 수 있습니다.

> ⚠️ 본 프로젝트는 고려대학교 학생을 대상으로 제작한 개인 학습용 프로젝트이며, 고려대학교의 공식 서비스가 아닙니다.

## 🌟 주요 기능

### 📅 월별 캘린더

* 월 단위 일정 확인
* 날짜별 과제 및 시험 표시
* 특정 날짜 클릭 시 해당 일정만 조회 가능

### 📝 과제 관리

* 과제 추가, 수정, 삭제
* 과목명 및 과제명 입력
* 중요도 설정 (상/중/하)
* D-Day 자동 계산

### ✍️ 시험 관리

* 시험 일정 등록
* 시험 시간 입력
* 강의실 정보 저장
* 시험일까지 남은 기간 표시

### 🔍 필터 및 정렬

* 전체 일정 보기
* 과제만 보기
* 시험만 보기
* D-Day 순 정렬
* 중요도 순 정렬

### 📊 학업 현황 대시보드

* 전체 일정 개수
* 남은 과제 수
* 남은 시험 수
* D-7 이내 마감 임박 일정 수 표시

### 💾 자동 저장

* LocalStorage 기반 데이터 저장
* 새로고침 후에도 일정 유지
* 별도 로그인 없이 사용 가능

## 🎨 디자인 특징

* 고려대학교 Crimson & Gold 컬러 테마
* 반응형(Responsive) 웹 디자인

## 🚀 GitHub Pages 배포 방법

1. GitHub Repository 생성
2. index.html, style.css, script.js 업로드
3. Settings → Pages 이동
4. Source를 "Deploy from a branch"로 설정
5. Branch를 main / root로 설정 후 저장
6. 생성된 GitHub Pages URL 접속

## 💡 제작 배경
